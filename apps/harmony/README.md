# HarmonyOS NEXT 客户端

这是纯血鸿蒙 ArkTS / ArkUI 工程，不是 Android APK。目标能力与 Android 一致：家庭成员、日历病历、附件、复查提醒、用药日历以及 `.htbackup v4`。

当前电脑尚未安装 DevEco Studio，也没有华为开发者账号或 HarmonyOS NEXT 测试设备，因此仓库提供工程源码、加密 RDB 数据层和平台适配接口，但签名 HAP 与真机后台提醒必须在这些条件具备后验收。

当前开发预览已完成：

- 加密 RDB 状态存储、启动完整性检查、旧 JSON 状态规范化及事务迁移备份。
- 家庭成员选择、当前成员日历与搜索隔离、病历新增及保存前重新打开核对/编辑；新增表单固定所属成员。
- 复查默认提前 3 天、完成记录和全部有效成员提醒重建。
- 用药月历、5 分钟实际服用时间、过去/当天服药与跳过修正、未来日期只读，以及次日生效的历史计划版本。
- `.htbackup v4` 清单模型、成员/引用/顺序/有效期/附件校验逻辑及 CI 黄金样本检查。
- 备份合并预览、UUID 去重与逐项冲突选择领域逻辑；默认保留本机版本。

仍待 DevEco 工具链验证和实现的发布门槛包括：附件文件选择/图片与 PDF 查看/安全删除、PBKDF2 + AES-GCM 加密 ZIP 的完整导入导出、HUKS 密钥适配、系统身份验证锁、冲突选择界面、编辑/归档的完整页面和真机后台通知。因此当前不能作为客户 HAP 发布。

导入 DevEco Studio 后：

1. 安装仓库声明的 HarmonyOS SDK。
2. 登录华为开发者账号并配置调试签名。
3. 执行 `hvigorw clean assembleHap`。
4. 按 `docs/DEVICE_QA_CHECKLIST_HARMONY.md` 完成模拟器和真机检查。
