# 病程日历 Android 1.3.0

## 本次改进

- 病历、单个检查报告、复查计划和药物删除后先进入 30 天回收站。
- 回收站按当前家庭成员隔离，可查看剩余天数并恢复原项目。
- “永久删除”必须再次确认；确认后不可恢复。
- 删除病历时其附件一同进入回收站；恢复病历时只恢复本次随病历删除的附件，不会误恢复此前单独删除的报告。
- 回收站内的复查和药物停止提醒，恢复后重新建立有效提醒。
- 加密备份升级为 `.htbackup v5`，完整保存回收站内容，并兼容导入 v1、v2、v3、v4。
- 启动时自动清理超过 30 天的回收站内容；文件处理失败时保留项目供后续重试。

## 安全升级

- 版本为 `1.3.0`（`versionCode 13`）。
- Room 数据库升级至 v8，使用正式 7→8 事务迁移并校验数量和外键。
- 保持 `applicationId=com.healthtimeline.app` 和原发布签名。
- 应用继续不申请 `INTERNET` 权限。

请直接覆盖安装，**不要卸载旧版，不要清除应用数据**。升级前建议先导出一份加密备份。
