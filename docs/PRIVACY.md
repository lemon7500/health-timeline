# 隐私说明

病程日历只在设备本地处理病历、诊断、用药、提醒和检查报告。三端不需要账号，不申请联网权限，也不接入广告、统计或崩溃上传服务。

Android 数据库使用 SQLCipher，密钥由 Android Keystore 保护；iOS 数据库使用 SQLCipher，密钥存放在 Keychain；HarmonyOS NEXT 使用加密 RDB。附件保存在各系统应用沙箱中。Android 可选用系统指纹、面容或锁屏密码保护进入应用，应用不保存独立解锁密码。锁屏通知仅显示“病程日历提醒”，不显示成员姓名、病情或药名。

用户主动导出的 `.htbackup` 使用 PBKDF2-HMAC-SHA256（210,000 次）派生密钥和 AES-256-GCM 加密。v3 备份包含全部家庭成员的资料。密码不保存、不可找回；备份文件与密码必须分开保管。

卸载应用或清除应用数据会删除本地数据库和私有附件。执行前必须导出并验证备份。
