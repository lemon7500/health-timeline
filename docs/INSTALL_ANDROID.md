# 安装与备份说明

## 安装 APK

1. 从 GitHub Releases 下载 `HealthTimeline-1.3.0.apk`，并按发布页提供的 `SHA256SUMS.txt` 校验文件。
2. 在文件管理器中点击 APK；首次安装时，按系统提示允许该文件管理器“安装未知应用”。
3. 安装完成后关闭“安装未知应用”权限。
4. 首次启动时允许通知权限。
5. 打开“设置 → 安全与提醒检查”，允许通知和精确闹钟、检查后台运行，并发送一次 10 秒测试提醒。

华为/荣耀系统可能还需要在“应用启动管理”中允许自动启动、后台活动和关联启动。Redmi/小米系统通常需要允许自启动，并将电池策略设为“无限制”。菜单名称会因机型和系统版本不同而变化。

## 升级

新版 APK 必须使用同一 `applicationId` 和同一发布签名。请直接点击新版 APK 覆盖安装；**不要卸载旧版，也不要清除应用数据**。

从旧版更新到 1.3.0 时，正式数据库迁移会依次补齐成员、病历顺序、历史用药计划、疗程恢复状态和回收站字段。Room 7→8 只增加删除时间与附件更新时间，并在事务内核对逐表数量和外键；失败会整体回滚，不会自动清库。原分类、病历、附件、复查、药物、打卡、数字主键、UUID 和附件路径均保留。发布者必须永久安全保管原签名密钥，否则后续 APK 无法覆盖升级。

## 安全与提醒检查

1. 打开“设置 → 安全与提醒检查”。
2. 确认通知总开关、复查提醒类别、用药提醒类别和精确闹钟均为正常。
3. 检查标准电池优化；华为、荣耀和 Redmi 还需按系统要求允许自启动及后台活动。
4. 点击“发送 10 秒测试提醒”，确认通知可以出现。
5. 点击“检查数据库和全部附件”。检查只读取并核对数据，不会修改或上传资料。
6. 需要协助排查时可导出诊断报告；报告不包含姓名、病历正文、病名、药名、附件名称、路径或 UUID。

安装前建议先在旧版“设置”中导出一份加密备份。安装后逐项核对病历、附件、复查、用药和回收站，再导出一份新的 v5 备份。

## 导出备份

1. 打开“设置 → 导出加密备份”。
2. 设置至少 8 位密码并再次确认。
3. 选择手机本地或 U 盘中的保存位置。
4. 将 `.htbackup` 文件和密码分开保管。

## 恢复备份

1. 打开“设置 → 导入或恢复备份”，选择 `.htbackup` 文件。
2. 输入导出时使用的密码，等待完整验证。
3. v5 备份包含整个家庭、病历顺序、历史用药计划和回收站；导入时会显示新增、重复、可更新和冲突数量，默认保留本机冲突。v3、v4 备份会在验证后安全转换。
4. v2 单人备份会合并到当前选中的成员；请在导入前确认当前成员正确。
5. 旧 v1 备份没有稳定 UUID，可“作为新资料导入”当前成员，或在再次确认后整体替换；重复作为新资料导入会产生重复记录。

整体替换前应用会强制要求选择位置导出当前数据安全备份，同时在私有目录保留最近三份自动安全备份。导出或验证失败时不会替换现有数据。

## 重要提醒

- 忘记备份密码后无法恢复数据。
- 卸载、清除应用数据或手机损坏都会删除本地记录。
- 本应用只用于记录和提醒，不能替代医生诊断或用药指导。
