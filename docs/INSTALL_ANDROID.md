# 安装与备份说明

## 安装 APK

1. 从 GitHub Releases 下载 `HealthTimeline-1.2.0.apk`，并按发布页提供的 `SHA256SUMS.txt` 校验文件。
2. 在文件管理器中点击 APK；首次安装时，按系统提示允许该文件管理器“安装未知应用”。
3. 安装完成后关闭“安装未知应用”权限。
4. 首次启动时允许通知权限。
5. 在“设置”页允许精确闹钟，并检查系统的后台运行和电池优化设置。

华为/荣耀系统可能还需要在“应用启动管理”中允许自动启动、后台活动和关联启动。Redmi/小米系统通常需要允许自启动，并将电池策略设为“无限制”。菜单名称会因机型和系统版本不同而变化。

## 升级

新版 APK 必须使用同一 `applicationId` 和同一发布签名。请直接点击新版 APK 覆盖安装；**不要卸载旧版，也不要清除应用数据**。

从 1.1.0 更新到 1.2.0 时，正式数据库迁移会创建默认成员“本人”，并把原有分类、病历、附件、复查、药物和打卡完整关联到该成员；原数字主键、UUID 和附件路径均保留。发布者必须永久安全保管原签名密钥，否则后续 APK 无法覆盖升级。

安装前建议先在旧版“设置”中导出一份加密备份。安装后逐项核对病历、附件、复查和用药记录，再导出一份新的 v3 备份。

## 导出备份

1. 打开“设置 → 导出加密备份”。
2. 设置至少 8 位密码并再次确认。
3. 选择手机本地或 U 盘中的保存位置。
4. 将 `.htbackup` 文件和密码分开保管。

## 恢复备份

1. 打开“设置 → 导入或恢复备份”，选择 `.htbackup` 文件。
2. 输入导出时使用的密码，等待完整验证。
3. v3 备份包含整个家庭；导入时会显示新增、重复、可更新和冲突数量，默认保留本机冲突。
4. v2 单人备份会合并到当前选中的成员；请在导入前确认当前成员正确。
5. 旧 v1 备份没有稳定 UUID，可“作为新资料导入”当前成员，或在再次确认后整体替换；重复作为新资料导入会产生重复记录。

整体替换前应用会强制要求选择位置导出当前数据安全备份，同时在私有目录保留最近三份自动安全备份。导出或验证失败时不会替换现有数据。

## 重要提醒

- 忘记备份密码后无法恢复数据。
- 卸载、清除应用数据或手机损坏都会删除本地记录。
- 本应用只用于记录和提醒，不能替代医生诊断或用药指导。
