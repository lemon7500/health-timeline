# 安装与备份说明

## 安装 APK

1. 将 `病程日历-1.1.0-release.apk` 复制到手机。
2. 在文件管理器中点击 APK；首次安装时，按系统提示允许该文件管理器“安装未知应用”。
3. 安装完成后关闭“安装未知应用”权限。
4. 首次启动时允许通知权限。
5. 在“设置”页允许精确闹钟，并检查系统的后台运行和电池优化设置。

华为/荣耀系统可能还需要在“应用启动管理”中允许病程日历自动启动、后台活动和关联启动。菜单名称会因机型和系统版本不同而变化。

## 升级

后续 APK 必须使用同一 `applicationId` 和同一发布签名。直接安装新版即可保留数据。不要丢失 `release-private` 中的发布密钥，否则无法覆盖升级现有安装。

从 1.0.0、1.0.1 或 1.0.2 更新到 1.1.0 时，请直接覆盖安装，不能先卸载，也不要清除应用数据。1.1.0 使用正式数据库迁移为每条资料增加跨平台 UUID；原病历、附件、提醒、用药记录和本地数字主键都会保留。

## 导出备份

1. 打开“设置 → 导出加密备份”。
2. 设置至少 8 位密码并再次确认。
3. 选择手机本地或 U 盘中的保存位置。
4. 将 `.htbackup` 文件和密码分开保管。

## 恢复备份

1. 打开“设置 → 导入或恢复备份”，选择 `.htbackup` 文件。
2. 输入导出时使用的密码，等待完整验证。
3. v2 备份会显示新增、重复、可更新和冲突数量；默认保留本机冲突，确认后选择“安全合并”。
4. 旧 v1 备份没有稳定 UUID，只能在再次确认后整体替换。

整体替换前应用会在私有目录保留最近三份自动安全备份。普通用户仍应在操作前额外导出一份可自行保管的备份。

## 重要提醒

- 忘记备份密码后无法恢复数据。
- 卸载、清除应用数据或手机损坏都会删除本地记录。
- 本应用只用于记录和提醒，不能替代医生诊断或用药指导。
