# 华为/荣耀真机验收清单

记录测试机型、系统版本、Android API、测试日期和测试人，并在至少一台华为及一台荣耀手机上完成。

## 安装与隐私

- [ ] 签名 APK 可正常侧载、首次启动和覆盖升级。
- [ ] 系统权限页确认应用没有网络权限。
- [ ] 拒绝通知权限时，应用设置页显示明确警告。
- [ ] 锁屏通知仅显示“复查提醒”或“用药提醒”，不暴露病情及药名。

## 病历和附件

- [ ] 7 月 9 日新增病历后，月历日期下显示标题。
- [ ] 同一天建立 3 条记录时显示两个标题和 `+1`。
- [ ] 病历新增、编辑、删除及病情分类归档行为正确。
- [ ] 连续快速点击两次“保存”，只生成一条记录。
- [ ] 同一病历可导入多张照片和多个 PDF，重启应用后仍可查看。
- [ ] 相机拍照、图片缩放、PDF 翻页正常。
- [ ] 超过 100 MB、损坏、无空间或不支持的附件不会留下半成品。

## 复查提醒

- [ ] 7 月 9 日设置每 3 个月，下一次为 10 月 9 日。
- [ ] 1 月 31 日每月提醒依次为 2 月末、3 月 31 日。
- [ ] 每周四提醒可跨月和跨年。
- [ ] 提前 0/1/3/7 天和提醒时间正确。
- [ ] 提醒触发后显示待处理项，可标记完成或跳过。
- [ ] 同一个提醒被系统重复投递时只生成一个待处理项，且只有完成/跳过后才推进下一次日期。
- [ ] 重启、修改时区和修改系统时间后仍有提醒。
- [ ] 关闭精确闹钟权限时显示降级警告，并仍收到可能延迟的提醒。

## 用药

- [ ] 每日 08:00、20:00 各产生一剂且分别提醒。
- [ ] 应用内“已服/跳过”和通知“已服”只写入一次。
- [ ] 修改剂量后，历史记录仍保留原剂量快照。
- [ ] 结束疗程后不再产生提醒，历史日志保留。
- [ ] 尚未到开始日期及已经超过结束日期的药物不产生提醒。

## 备份恢复

- [ ] 导出包含病历、提醒、用药和全部附件的加密备份。
- [ ] 正确密码恢复后数据和附件完整。
- [ ] 错误密码、文件损坏、不支持版本和空间不足均不改变当前数据。
- [ ] 恢复过程中强制结束应用并重新启动：原数据或已完整提交的新数据可用，不出现数据库与附件错配。
- [ ] 从 1.0.0 或 1.0.1 覆盖安装 1.0.2 后，既有病历、附件、提醒和用药历史全部保留。
- [ ] 日历标题最多显示两行，同一天两条记录分别显示在独立浅色圆角标签中。
- [ ] 搜索标题、分类、诊断、治疗、用药和备注均可找到记录，点击结果能跳到对应日期。
- [ ] 卸载并重新安装后，可通过备份恢复全部内容。

## 电池与后台

- [ ] 自动启动、后台活动和关联启动均按机型要求开启。
- [ ] 熄屏 2 小时及隔夜后，复查和用药通知仍能出现。
- [ ] 低电量模式下记录实际延迟；若系统强制延迟，在安装说明中注明该机型设置路径。
