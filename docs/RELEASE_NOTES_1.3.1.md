# 病程日历 Android 1.3.1 候选更新

## 本次改进

- 新增独立“今日”首页，底部入口为“今日、日历、复查、用药、设置”。冷启动进入今日，从后台返回保留原页面。
- 首页只显示当前家庭成员，提供“记录今天病情”快捷入口。
- 今日用药展示计划、历史剂量、实际时间及已服、跳过、未记录状态；未记录事项优先，已记录内容可展开查看。
- 首页可确认后记录已服或跳过，实际时间使用每 5 分钟一档的滚轮；已记录事项进入当天详情修正，防止重复打卡。
- 已结束疗程当天仍可查看历史内容，未记录项标注“疗程已结束”；按需药物可补记，不生成待服计划。
- 复查分为逾期未处理和今天起连续 7 天，可在首页确认到期事项完成或跳过；未来事项仅查看，打开首页不会推进周期。
- 通知未开启或尚未生成待处理记录时，首页仍显示复查事项。权限和备份异常可从简短提示进入“安全与提醒检查”。

## 安全升级

- 版本为 `1.3.1`（`versionCode=14`），保持 `applicationId=com.healthtimeline.app` 和原发布签名。
- Room 保持 v8，`.htbackup` 保持 v5；从 1.3.0 覆盖升级无需新增迁移，不清库、不改写历史内容。
- 继续完全离线，不增加网络或其他权限；首页不提供诊断或是否应服药的判断，未记录不等于漏服。

请直接覆盖安装，**不要卸载旧版，不要清除应用数据**。升级前建议导出加密备份，升级后核对病历、附件、复查、用药、成员与回收站。

## 发布状态

本版本为候选更新。新的自动测试、构建结果以实际验证报告为准；华为、荣耀和 Redmi 真机覆盖升级及首页操作仍需按验收清单完成。通过数据保护及真机验收后，才公开发布 GitHub Release。

系统省电与厂商后台限制可能导致提醒延迟；首页显示待处理事项不代表通知一定准时。本轮不包含云同步、联网 AI或 iOS/HarmonyOS NEXT 新功能。
