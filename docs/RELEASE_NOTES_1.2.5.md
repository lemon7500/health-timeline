# 病程日历 Android 1.2.5

## 本次修复

- 结束用药疗程时保存准确的结束日期和时间。
- 结束当天以及此前的用药计划、服药和跳过记录继续保留在用药日历中。
- 用药日历下方新增“当日用药 / 用药疗程 / 已结束用药”二级栏目，减少页面纵向滚动。
- “已结束用药”按结束时间倒序显示，并保留原剂量、用药说明和历史服药时间。

## 安全升级

- 版本为 `1.2.5`（`versionCode 10`），数据库使用正式 Room `5→6` 迁移。
- 迁移只增加疗程结束时间字段；旧版已归档药物使用原最后更新时间补齐，不删除任何现有表或记录。
- 保持 `applicationId=com.healthtimeline.app`。发布 APK 必须继续使用原签名，才能覆盖安装并保留手机里的数据。

下载 `HealthTimeline-1.2.5.apk` 后，请直接覆盖安装。**不要卸载旧版，不要清除应用数据。**
