# HarmonyOS NEXT 真机测试清单

> 当前源码尚未完成 DevEco 构建和真机验收。以下项目全部通过前，不得向客户提供 HAP。

- [ ] 使用开发签名 HAP 覆盖安装上一测试版本，确认成员、病历、复查、用药、打卡和附件数量、UUID、内容及 SHA-256 不变。
- [ ] 模拟旧状态规范化中断，确认事务回滚且 `migration_backup` 保留升级前状态。
- [ ] 拒绝通知权限后应用保持可用并显示明确提示；再次授权后可重建全部有效成员的提醒。
- [ ] 验证每三个月、每周四、跨年、月末 31 日和系统时区变化。
- [ ] 验证用药月历、每 5 分钟实际服用时间、已服/跳过修正、防重复记录和未来日期只读。
- [ ] 修改药物计划后，过去日期仍显示旧时间和旧剂量，新计划从次日开始。
- [ ] 切换成员后日历、搜索、复查和用药完全隔离；已打开的病历表单仍保存给打开时的成员。
- [ ] 导入多张图片和多个 PDF，重启后仍可打开；单独删除附件和删除病历都不会留下错误引用。
- [ ] 错误密码、损坏备份、缺失附件、错误 SHA-256、空间不足和导入中断不改变现有数据。
- [ ] 验证 Android/iOS 导出的 v4 多成员备份可以导入，并可重新导回 Android；同时验证 v2/v3 兼容转换。
- [ ] 相同备份导入两次不重复；冲突默认保留本机，逐项采用导入版本只改变所选项目。
- [ ] 验证 HUKS 密钥保护、系统身份验证锁、锁屏隐私通知和应用沙箱附件保护。
- [ ] 在系统应用启动/电池设置中分别测试默认、允许后台和严格限制三种情况。
