# HarmonyOS NEXT 真机测试清单

- 使用开发签名 HAP 覆盖安装上一测试版本，确认数据数量和附件校验值不变。
- 拒绝通知权限后应用保持可用并显示明确提示；再次授权后可重建提醒。
- 验证每三个月、每周四、跨年、月末 31 日和系统时区变化。
- 验证 08:00/20:00 用药提醒、已服、跳过和防重复记录。
- 导入多张图片和多个 PDF，重启后仍可打开；删除病历后附件同步清理。
- 错误密码、损坏备份、空间不足和导入中断不改变现有数据。
- 验证 Android 导出的 v3 多成员备份可以导入，并可重新导回 Android；同时验证 v2 单人备份兼容路径。
- 在系统应用启动/电池设置中分别测试默认、允许后台和严格限制三种情况。
