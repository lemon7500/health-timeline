1. 让 GitHub macOS CI 编译 iOS 新代码并修复所有编译/单测问题。

Android 的 `applicationId`、签名和 Room 升级路径独立保留；开发另外两端不会覆盖 Android 已有用户资料。iOS 与 HarmonyOS NEXT 必须先实现 `deletedAt` 及恢复/永久删除语义，才可接收 v5，禁止把 v5 当 v4 导入后丢弃回收站状态。
