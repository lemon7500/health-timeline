# 病程日历 Android 1.2.0

## 本次更新

- 新增家庭多人档案，日历、搜索、复查和用药可全局切换成员。
- 新增可选应用锁，支持手机指纹、面容或锁屏密码。
- 新增离线快速录入：一大段文字可按日期拆成多条病历，预览确认后原子保存。
- 用药提醒时间改为小时、分钟滚轮选择，分钟以 5 分钟为间隔。
- 通知加强隐私：锁屏只显示“病程日历提醒”。
- 备份升级为 v3，一份文件包含全家庭资料和附件；兼容导入 v2 单人备份，v1 可作为新资料导入或安全替换。
- 整体替换前强制导出当前数据安全备份。
- 1.1.0 原资料覆盖升级后自动归入“本人”，保留原病历、附件、提醒、药物和打卡。

## 安装与升级

下载 `HealthTimeline-1.2.0.apk` 后，建议先用 `SHA256SUMS.txt` 校验文件。

已经安装旧版时，请直接点击新版 APK 覆盖安装。**不要卸载旧版，不要清除应用数据。** 安装后先核对资料，再导出一份新的加密备份。

## 兼容性

- Android 8.0 及以上，包括可安装 Android APK 的华为、荣耀、Redmi/小米手机。
- 不支持 HarmonyOS NEXT 原生系统。
- 应用完全离线，不申请网络权限，也不会自动检查更新。

## 发布门槛

正式稳定版只在 Android CI、数据库迁移、备份完整性及华为、荣耀、Redmi 覆盖升级清单全部通过后发布。未完成真机清单的构建只能标记为预发布候选版。
