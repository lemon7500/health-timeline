# 病程日历 Android 1.2.6

## 本次改进

- “已结束用药”卡片增加“恢复疗程”。
- 结束疗程时保存原计划结束日期，并只暂停当前及未来用药时间表。
- 恢复疗程时恢复原计划结束日期、重新启用后续计划和本地提醒。
- 恢复不会删除或改写既有日历条目、服药时间、跳过状态及历史剂量。
- 已由 1.2.5 结束的疗程，升级后也会尽可能识别并恢复最后的时间表。

## 安全升级

- 版本为 `1.2.6`（`versionCode 11`），数据库使用正式 Room `6→7` 迁移。
- 迁移只增加恢复所需状态字段，不删除、不重建用户数据表。
- 保持 `applicationId=com.healthtimeline.app` 和原发布签名。

请直接覆盖安装，**不要卸载旧版，不要清除应用数据**。
