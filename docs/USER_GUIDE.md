# 病程日历使用指南

## 主要功能

- **今日总览**：打开软件查看当前家庭成员今日用药、逾期和近期 7 天复查，并可确认后打卡。
- **日历记录**：按日期保存病情、诊断、治疗、用药和备注；日期下可显示两行标题，并用浅色圆角标签区分不同事项。
- **快速录入**：简单内容可直接离线解析；复杂长文可复制通用 AI 整理提示词，脱敏后交给外部 AI 转成模板，再粘贴回来逐条核对。
- **家庭档案**：可为本人和家人分别保存资料，“今日、日历、复查、用药”共享当前成员。
- **快速搜索**：在日历顶部输入标题、病情、诊断、治疗、医院等关键词，点击结果即可查看对应记录。
- **复查提醒**：支持一次性、每隔若干天、每隔若干周和每隔若干月提醒，例如“每 3 个月”或“每周四”。
- **用药记录**：用月历按天查看计划时间、实际服药时间和状态，可补记或修正历史记录。
- **检查报告**：每条病历可保存多张图片和多个 PDF，单个文件最大 100 MB，也可单独删除。
- **30 天回收站**：删除的病历、单个报告、复查计划和药物会保留 30 天，可恢复或永久删除。
- **隐私保护**：可使用手机指纹、面容或锁屏密码保护应用。
- **加密备份**：一次备份整个家庭的全部资料和附件，也可先预览再合并或整体恢复。
- **安全检查**：集中检查通知、精确闹钟、电池优化、最近备份和数据库/附件完整性。

## 怎么使用

底部有“今日、日历、复查、用药、设置”五个入口。重新打开软件默认进入“今日”；从后台返回保留原页面。

1. 先在页面顶部选择家庭成员；需要新增成员时进入“设置 → 家庭档案”。
2. 在“日历”点击右下角 **+**。可逐项填写，也可在“快速录入”粘贴文字后点“解析并填入”。自然叙述中的每件事情尽量另起一行并以日期开头；解析出多条记录后，点每条的“展开核对”修改全部字段，再统一保存。
3. 复杂长文可展开“AI 辅助整理”，点击“复制 AI 整理提示词”。应用只复制提示词和空模板；请先删除姓名、身份证号、电话和住址等信息，再自行粘贴病历给外部 AI。把 AI 输出复制回来后仍须逐条核对，尤其是日期、病名、诊断、用药和医生。小标题必须以病名开头，例如“鼻窦炎术后复查”。

   多条模板之间另起一行写 `---`，下一行再填写“日期：”。“其他备注”是最后一个字段，其后的原文中出现“日期：”“医生：”或分号时不会被当成新字段；若无法确认记录边界，会提示你补充分隔符，不会静默拆错记录。
4. 打开一条病历，在“检查报告”中添加图片或 PDF；删除单个报告前会再次显示文件名确认。
5. 在“复查”点击 **+**，填写首次日期、重复周期和提醒时间；新建计划默认提前 3 天，可改为 0、1、3 或 7 天。
6. 在“用药”点击 **+**，填写药物并上下滑动选择提醒时间（每 5 分钟一档）。日历下方可切换“当日用药、用药疗程、已结束用药”：点日期查看当天计划、实际时间与状态；点“结束疗程”会记录结束日期和时间并停止后续提醒，但当天及此前记录不会消失。若误点结束，可在“已结束用药”点击“恢复疗程”，恢复原计划和后续提醒。编辑药物时新计划默认次日生效，过去的时间和剂量不会被改写。
7. 在日历搜索框输入关键词，点击结果可定位到对应日期。
8. 可在“设置”开启身份验证，并定期导出加密备份；密码与备份文件要分开保存。
9. 打开“设置 → 安全与提醒检查”，确认各项状态，发送 10 秒测试提醒，并定期运行数据完整性检查。需要协助排查时可导出不含医疗正文的诊断报告。
10. 误删内容时打开“设置 → 回收站”，确认当前家庭成员后点击“恢复”。超过 30 天会在下次启动时自动清理；“永久删除”不可撤销，操作前应先导出备份。

## 今日总览怎么用

- 顶部先确认日期和家庭成员；点击“记录今天病情”新增今天的病历，取消不会保存。
- “今日用药”先显示未记录事项，较多时点击“查看全部”；已服和跳过记录可展开查看。点击“已服”后核对成员、药名、剂量及实际时间，可用每 5 分钟一档的滚轮调整，再确认；“跳过”也需确认。已记录项目进入当天用药详情修正，不重复打卡。
- 按需药物点击“补记按需用药”，不会自动生成待服计划。已结束疗程当天仍显示历史内容，但未记录项目标注“疗程已结束”，不提供继续服药按钮。
- “逾期未处理”和“近期 7 天”按复查日期显示。到期或逾期事项可以确认完成或跳过；未来事项仅查看详情。仅查看首页不会改变复查日期，通知关闭也能看到应处理事项。
- 安全提示出现时，点击进入“安全与提醒检查”。请核对通知、提醒类别、精确闹钟及备份状态；从未备份或最近备份超过 30 天会提示。

## 重要说明

- 从 GitHub Releases 下载新版后应直接覆盖安装，不要先卸载或清除数据。
- v5 加密备份会同时保存尚未过期的回收站内容。
- 归档成员会暂停该成员提醒，但历史资料仍会保留；有历史资料的成员不能删除。
- 卸载应用会删除本机资料，卸载或换机前务必导出备份。
- 首次使用请允许通知，并关闭手机对本应用的过度省电限制，否则提醒可能延迟。
- 当前可交付客户使用的是 Android 版；iOS 与 HarmonyOS NEXT 仍在开发和验证中。
- 本应用只用于记录与提醒，不提供诊断、处方或药物安全建议。
- 未记录不等于漏服；首页不判断是否应当服药。系统省电或后台限制仍可能使通知延迟。
- 1.3.1 为候选更新；华为、荣耀和 Redmi 真机覆盖升级及首页验收完成后才公开发布。

## 安全修复后的操作变化（尚未发布）

- 用药通知点击“核对并记录”后进入当天用药页面；开启应用锁时先验证身份，再核对并打卡，不会自动记为已服。
- 修改药物时，新时间默认从明天或疗程开始日中较晚的一天生效；今天剩余的旧计划继续提醒。不能把开始日期改到已经存在的历史计划或打卡之后，也不能结束尚未开始的疗程。
- 旋转屏幕或应用暂时锁定后，可继续填写未保存表单；取消、切换成员或重启进程会清除未保存内容，请及时保存。
- 为保护医疗隐私，Android 界面不能截屏或录屏。
- 本机附件损坏或缺失但有完整备份时，可通过合并备份修复对应文件。整体替换仍须先成功生成当前资料的安全备份；不能绕过错误直接覆盖。
