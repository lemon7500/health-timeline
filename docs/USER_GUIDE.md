# 病程日历使用指南

## 主要功能

- **日历记录**：按日期保存病情、诊断、治疗、用药和备注；日期下可显示两行标题，并用浅色圆角标签区分不同事项。
- **快速搜索**：在日历顶部输入标题、病情、诊断、治疗、医院等关键词，点击结果即可查看对应记录。
- **复查提醒**：支持一次性、每隔若干天、每隔若干周和每隔若干月提醒，例如“每 3 个月”或“每周四”。
- **用药记录**：登记药名、剂量、开始/结束日期和每日服药时间，并可标记“已服”或“跳过”。
- **检查报告**：每条病历可保存多张图片和多个 PDF，单个文件最大 100 MB。
- **加密备份**：Android 可导出带密码的 `.htbackup` 文件，也可先预览再合并或整体恢复。

## 怎么使用

1. 在“日历”点击右下角 **+**，填写日期、标题和病情资料后保存。
2. 打开一条病历，在“检查报告”中添加图片或 PDF。
3. 在“复查”点击 **+**，填写首次日期、重复周期和提醒时间。
4. 在“用药”点击 **+**，填写药物与服药时间；服药后点击“已服”，未服可点“跳过”。
5. 需要查找历史内容时，在日历搜索框输入关键词并点击结果。
6. 定期进入“设置”导出加密备份，并把备份文件和密码分开妥善保存。

## 重要说明

- 安装新版时应直接覆盖更新，不要先卸载；Android 的包名与原签名保持不变，覆盖升级会保留原资料。
- 卸载应用会删除本机资料，卸载或换机前务必导出备份。
- 首次使用请允许通知，并关闭手机对本应用的过度省电限制，否则提醒可能延迟。
- 当前可交付客户使用的是 Android 版；iOS 与 HarmonyOS NEXT 仍在开发和验证中。
- 本应用只用于记录与提醒，不提供诊断、处方或药物安全建议。
