# 病程日历使用指南

## 主要功能

- **日历记录**：按日期保存病情、诊断、治疗、用药和备注；日期下可显示两行标题，并用浅色圆角标签区分不同事项。
- **快速录入**：粘贴一大段带“日期、标题”等标签的文字，可自动拆成多天、多条病历，核对后一次保存。
- **家庭档案**：可为本人和家人分别保存资料，并在日历、复查、用药页切换当前成员。
- **快速搜索**：在日历顶部输入标题、病情、诊断、治疗、医院等关键词，点击结果即可查看对应记录。
- **复查提醒**：支持一次性、每隔若干天、每隔若干周和每隔若干月提醒，例如“每 3 个月”或“每周四”。
- **用药记录**：登记药名、剂量、开始/结束日期和每日服药时间，并可标记“已服”或“跳过”。
- **检查报告**：每条病历可保存多张图片和多个 PDF，单个文件最大 100 MB。
- **隐私保护**：可使用手机指纹、面容或锁屏密码保护应用。
- **加密备份**：一次备份整个家庭的全部资料和附件，也可先预览再合并或整体恢复。

## 怎么使用

1. 先在页面顶部选择家庭成员；需要新增成员时进入“设置 → 家庭档案”。
2. 在“日历”点击右下角 **+**。可逐项填写，也可在“快速录入”粘贴文字后点“解析并填入”。多条记录需让每条都以“日期：”开头，核对预览后再保存。
3. 打开一条病历，在“检查报告”中添加图片或 PDF。
4. 在“复查”点击 **+**，填写首次日期、重复周期和提醒时间。
5. 在“用药”点击 **+**，填写药物并上下滑动选择提醒时间（每 5 分钟一档）；服药后点击“已服”，未服可点“跳过”。
6. 在日历搜索框输入关键词，点击结果可定位到对应日期。
7. 可在“设置”开启身份验证，并定期导出加密备份；密码与备份文件要分开保存。

## 重要说明

- 从 GitHub Releases 下载新版后应直接覆盖安装，不要先卸载或清除数据。
- 归档成员会暂停该成员提醒，但历史资料仍会保留；有历史资料的成员不能删除。
- 卸载应用会删除本机资料，卸载或换机前务必导出备份。
- 首次使用请允许通知，并关闭手机对本应用的过度省电限制，否则提醒可能延迟。
- 当前可交付客户使用的是 Android 版；iOS 与 HarmonyOS NEXT 仍在开发和验证中。
- 本应用只用于记录与提醒，不提供诊断、处方或药物安全建议。
