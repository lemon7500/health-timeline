# 病程日历 Android 1.2.3

## 本次小版本更新

- AI 整理提示词明确要求病名必须位于小标题第一位，例如“鼻窦炎术后复查”。
- 新增保存前标题规范化：若 AI 或用户填写“术后复查鼻窦炎”，会自动整理为“鼻窦炎术后复查”。
- 病名原本已经位于标题开头时保持不变，不会重复添加。

## 安装与升级

下载 `HealthTimeline-1.2.3.apk` 后，使用 `SHA256SUMS.txt` 校验文件。已安装旧版时直接覆盖安装，**不要卸载旧版，不要清除应用数据**。

本次不修改数据库结构，保持 `applicationId=com.healthtimeline.app` 和原发布签名。原有日历、复查、用药、附件及家庭成员资料会继续保留。
