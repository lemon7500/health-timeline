# iPhone / iPad 验收清单

> 当前源码尚未完成真机签名验收。以下项目全部通过前，不得向客户提供 iOS 安装包。

## 安装与数据保护

- [ ] 在 iOS 16、当前最新版 iOS 各测试一台设备；至少覆盖一台 iPhone 和一台 iPad。
- [ ] 安装旧测试版并录入成员、病历、附件、复查、药物和打卡，再覆盖安装 1.2.4，逐项核对 UUID、数量、内容和附件 SHA-256。
- [ ] 强制结束应用、重启设备、修改时区后，资料仍可读取且提醒会重建。
- [ ] 开启系统验证锁，验证 Face ID/Touch ID、设备密码回退、取消验证、锁屏和离开应用超过 30 秒。
- [ ] 检查应用不包含网络权限或网络请求，锁屏通知不显示姓名、病情和药名。

## 病历与附件

- [ ] 月历标题显示两行、浅色圆角标签和 `+N`，搜索结果可打开对应病历。
- [ ] 快速录入复制的内容只有提示词和空模板，不包含输入框中的病历原文。
- [ ] AI 模板多日期、同日多事件按原文顺序展示；每条均可在保存前修改或删除。
- [ ] 缺少日期、标题、病名在前或“原文记录”时禁止批量保存；取消页面不产生记录。
- [ ] 批量保存失败时没有半批病历或空分类；已归档同名分类须经确认才恢复。
- [ ] 导入多张图片和多个 PDF，重启后均可查看；单独删除、重复点击和文件已丢失路径均不崩溃、不误删病历。

## 复查与用药

- [ ] 新建复查默认提前 3 天；2026-07-09 每 3 个月的下一次为 2026-10-09。
- [ ] 每周四跨月、跨年、时区变化后仍正确；通知权限拒绝时有明确提示。
- [ ] 用药月历按日显示计划、已服、跳过和未记录；过去/当天可补记，未来日期只读。
- [ ] 实际服用时间以 5 分钟为间隔；重复打卡被阻止，已有记录可以修正状态和时间。
- [ ] 修改用药计划后，旧日期继续显示旧时间和剂量，新版本只从选择的生效日开始。

## 备份与故障路径

- [ ] iOS 导出的 v4 备份可由 Android 读取；Android v2/v3/v4 备份可在 iOS 预览。
- [ ] 相同备份导入两次不产生重复；冲突默认保留本机，逐项选择导入版本后仅对应项目改变。
- [ ] 整体替换前自动生成安全备份；设置页可以导出最近一份，并能用原密码恢复。
- [ ] 错误密码、损坏容器、缺失附件、错误 SHA-256、空间不足和导入中断均不改变现有数据库及附件。
- [ ] 模拟数据库提交失败，确认新安装附件会清理、旧附件仍保留；重新启动后清理无引用的恢复目录。
