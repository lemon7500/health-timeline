# 病程日历 Android 1.2.1

## 本次小版本更新

- 提升中文自然病历中的医生姓名识别，支持“找某医生”“向某主任咨询”“某医生建议”等常见表达。
- 收紧诊断提取范围，减少把手术建议、观察事项和用药内容错误归入诊断。
- 多日期文字解析后可逐条展开，在保存前修改日期、标题、病情分类、医生、诊断、治疗、用药和备注。
- 小标题继续自动包含病情分类名称。
- 修复长文本达到字段上限后可能被静默截断的问题；现在保留输入并明确提示修改。

## 安装与升级

下载 `HealthTimeline-1.2.1.apk` 后，使用 `SHA256SUMS.txt` 校验文件。已安装旧版时直接覆盖安装，**不要卸载旧版，不要清除应用数据**。

本次不修改数据库结构，保持 `applicationId=com.healthtimeline.app` 和原发布签名。日历、复查、用药、附件及家庭成员资料会继续保留。
