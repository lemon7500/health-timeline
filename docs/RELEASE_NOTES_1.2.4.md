# 病程日历 Android 1.2.4

## 本次更新

- 检查报告支持逐张图片、逐份 PDF 二次确认后安全删除，并能恢复异常中断时尚未提交的删除。
- 家庭成员页面将“称呼”和“关系”合并为“关系”，旧数据继续保留兼容。
- 新建复查计划默认提前 3 天提醒，已有计划不改变。
- 用药页新增月历与当日明细，可补记和修正历史用药；编辑药物会创建有生效日期的时间表版本，不覆盖过去计划和剂量。
- 快速录入备注保存对应“原文记录”，批量记录及原文编号顺序在日历和备份中保持稳定。
- 数据库升级为 Room v5，备份升级为 `.htbackup` v4，并继续兼容 v1、v2、v3。

## 安装与升级

下载 `HealthTimeline-1.2.4.apk` 后，使用 `SHA256SUMS.txt` 校验文件。已安装旧版时请直接覆盖安装，**不要卸载旧版，不要清除应用数据**。

本版保持 `applicationId=com.healthtimeline.app`，正式 APK 必须继续使用原发布签名。Room 4→5 迁移在事务中补齐新字段，原有家庭成员、日历、病历、附件、复查、药物、打卡和提醒均保留；安装前仍建议先导出一份加密备份。
