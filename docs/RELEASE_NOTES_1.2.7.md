# 病程日历 Android 1.2.7

## 本次改进

- 设置页新增“安全与提醒检查”二级页面，避免原设置页继续变长。
- 同时检查通知运行时权限、应用通知总开关、复查/用药通知类别及精确闹钟状态。
- 显示 Android 标准电池优化状态，并提示华为、荣耀、Redmi 仍需人工确认厂商自启动和后台开关。
- 可安排一条约 10 秒后的测试提醒，验证应用、闹钟和通知链路。
- 只在加密备份成功写出后记录最近备份时间；从未备份或超过 30 天时显示提示。
- 可手动检查数据库、外键、附件是否存在、文件大小和 SHA-256，检查过程只读且不修改资料。
- 可导出本地诊断报告；报告不包含姓名、病历正文、病名、药名、附件名称、文件路径或数据 UUID。

## 安全升级

- 版本为 `1.2.7`（`versionCode 12`）。
- 保持 Room v7 和 `.htbackup v4`，不增加数据库迁移。
- 保持 `applicationId=com.healthtimeline.app` 和原发布签名。
- 应用继续不申请 `INTERNET` 权限。

请直接覆盖安装，**不要卸载旧版，不要清除应用数据**。
